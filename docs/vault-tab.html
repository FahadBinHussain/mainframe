mainframe password tab

Type the Bitwarden master password. This page encrypts it in your browser with a one-time RSA key. If opened via phone approval, the encrypted ciphertext is sent securely to the remote runner via relay (the relay only sees ciphertext and cannot decrypt it). For local desktop runs, the encrypted file is downloaded to your machine. The password itself is never sent unencrypted anywhere.
